# 广州中小厂投递策略

你现在的目标是暑期实习，不是一步冲到顶级大厂核心 Agent 岗，所以策略要更现实一点。

## 1. 先定标签

### 主标签

- `Java 后端`
- `后端开发`

### 辅标签

- `AI 应用开发`
- `Agent 应用开发`

建议你把自己包装成：

**会做 AI 应用落地的 Java 后端**

这样对广州本地中小厂更友好。

## 2. 适合投的公司类型

- 互联网中小厂
- ToB 软件公司
- 传统行业数字化团队
- AI 应用创业公司
- 游戏工具链、内容平台、AIGC 相关团队

## 3. 投递节奏

### 第一阶段

- 先投 20 到 30 家
- 优先广州本地和可远程实习
- 不要只盯头部大厂

### 第二阶段

- 根据面试反馈调整简历
- 如果后端题答不稳，就继续加强 Java 基础
- 如果 Agent 方向被问得多，就补工具调用、RAG、提示词和流程编排

### 第三阶段

- 每周复盘投递结果
- 记录哪些岗位更看重 Java，哪些更看重 AI 应用
- 继续筛选更适合你的方向

## 4. 广州本地求职建议

广州的实习市场里，中小厂往往更看重这几件事：

- 代码能不能写
- 项目能不能跑
- 后端思维是否完整
- 沟通是否清楚
- 能不能尽快上手业务

所以你的项目要突出：

- 有真实后端链路
- 有异步任务
- 有缓存和消息队列
- 有 AI 亮点，但不虚

## 5. 简历投递侧重点

### 如果投 Java 后端

- 项目写成业务系统
- 强调接口设计、任务流、缓存、队列、数据库
- Agent 作为加分项

### 如果投 AI 应用

- 项目写成 Agent + 工具调用
- 强调自然语言驱动业务动作
- 后端工程能力作为底层支撑

## 6. 哪些公司更适合你

- 有后端岗位的 AI 应用公司
- 有内容生成、智能体平台、AIGC 应用的团队
- 游戏工具、数字内容、内容中台方向

## 7. 哪些坑要避开

- 不要把自己写得太像研究型人才
- 不要把 Agent 讲得太玄
- 不要只讲概念不讲工程
- 不要只投大厂，容易被周期拖住

## 8. 你可以怎么和面试官说

> 我现在的主能力是 Java 后端，项目里做了 Agent 和 AIGC 的落地能力，所以我会优先找既能做后端业务、又能接 AI 应用的岗位。这样我能比较快上手，同时也能继续往 Agent 方向积累。

## 9. 结合你的背景

你是广州、二本、智能科学与技术，这个组合不是劣势，反而有个好处：

- 你可以更灵活地同时投 Java 和 AI 应用
- 你有理由讲“我在做 AI 应用落地”
- 你更适合先拿一段实习，再逐步提升平台

## 10. 最后一句建议

别纠结自己是不是“够不够资格”，你现在更重要的是：

**把项目做稳，把表达做清楚，把投递做持续。**
