# 面试准备清单

这份清单按 `Java 后端`、`AI/Agent` 和 `项目追问` 三部分整理，你可以直接照着复习。

## 1. Java 后端基础

### 必会知识

- `Java` 基础语法、集合、泛型、异常
- `JVM` 基本概念
- `Spring Boot` 常用注解
- `Spring MVC` 请求流程
- `Spring Security` 基本鉴权流程
- `MySQL` 索引、事务、隔离级别
- `Redis` 常见数据结构、缓存穿透/击穿/雪崩
- `RabbitMQ` 消息确认、重试、死信队列

### 高频问题

- `@RestController` 和 `@Controller` 有什么区别
- `@Transactional` 为什么有时候不生效
- `Redis` 为什么能提高接口性能
- `MQ` 如何保证消息可靠性
- 数据库事务的隔离级别有哪些
- 索引为什么能加速查询

## 2. AI / Agent 基础

### 必会知识

- `Agent` 和普通聊天接口的区别
- 工具调用的作用
- 提示词优化的作用
- 流式输出怎么做
- 什么场景适合接 `RAG` 或图谱

### 高频问题

- 你的 Agent 是怎么工作的
- 为什么用 `LangChain4j`
- 为什么要先做提示词优化
- 什么是工具调用
- 知识图谱比普通数据库强在哪里

## 3. 项目追问

### 你项目里最容易被问的点

- 为什么要用 `RabbitMQ`，不是直接同步调用
- `Redis` 在这个项目里解决了什么问题
- `MinIO` 为什么不直接返回本地文件路径
- `Neo4j` 为什么比 MySQL 更适合存角色关系
- 任务状态怎么设计
- 任务失败了怎么处理
- `JWT` 怎么校验身份
- 如果 `ComfyUI` 很慢，系统怎么避免阻塞

### 推荐回答思路

- 先讲业务目标
- 再讲技术选择
- 最后讲带来的收益

比如：

> 我把生图流程拆成任务提交和任务执行两段，是为了避免请求线程被长时间阻塞。入口只负责创建任务并投递消息，真正耗时的生成由消费者异步处理，这样系统更稳定，也方便做状态追踪和失败重试。
