AIGC-GameFlow 快速启动

1. Copy-Item .env.template .env
2. docker compose up -d --build
3. POST http://localhost:8080/user/register
4. POST http://localhost:8080/user/login 获取 JWT
5. POST http://localhost:8080/api/generation/jobs
   Header: Authorization: Bearer <JWT>
   Header: Idempotency-Key: 任意 8 至 128 字符唯一键
   Body: {"prompt":"demo","preferredProvider":"WANX"}

启动前请在 .env 中配置 DASHSCOPE_API_KEY。Compose 默认使用 wan2.7-image-pro，调用可能产生费用。
RabbitMQ: http://localhost:15673
MinIO: http://localhost:9101

IDEA 开发模式：
1. docker compose up -d mysql redis rabbitmq minio
2. IDEA 环境变量设置 SPRING_PROFILES_ACTIVE=local 和 DASHSCOPE_API_KEY
3. 运行 aigc.gameflow.Main
4. 本地端口：MySQL 3307、Redis 6380、RabbitMQ 5673、MinIO 9100
5. RabbitMQ 管理台：http://localhost:15673
