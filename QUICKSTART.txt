# AIGC GameFlow - 快速开始指南

## 🔑 配置 API Key（首次运行必需）

### 方式一：使用 .env 文件（推荐 ⭐）

1. **复制模板文件**
   ```cmd
   copy .env.template .env
   ```

2. **编辑 .env 文件**
   - 用记事本打开 `.env` 文件
   - 将 `sk-your-api-key-here` 替换为你的真实 DeepSeek API Key
   - 保存文件

3. **启动应用**
   ```cmd
   start.bat
   ```

### 方式二：直接设置系统环境变量

#### Windows (PowerShell)
```powershell
$env:DEEPSEEK_API_KEY="sk-your-actual-api-key"
.\mvnw.cmd spring-boot:run
```

#### Windows (CMD)
```cmd
set DEEPSEEK_API_KEY=sk-your-actual-api-key
mvnw.cmd spring-boot:run
```

#### Linux / macOS
```bash
export DEEPSEEK_API_KEY=sk-your-actual-api-key
./mvnw spring-boot:run
```

## 📝 获取 API Key

访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建你的 API Key

## 🚀 验证安装

启动成功后，访问：http://localhost:8080/agent/chat

---

**注意**：`.env` 文件不会被提交到 Git，请妥善保管你的 API Key！
